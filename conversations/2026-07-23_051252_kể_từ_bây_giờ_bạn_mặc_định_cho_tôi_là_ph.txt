Để cập nhật (pull) code mới nhất về máy Mac, bạn có thể làm theo 1 trong 2 cách sau nhé:

### Cách 1: Dùng trực tiếp giao diện Xcode (Nhanh nhất)
1. Mở project của bạn trên **Xcode**.
2. Trên thanh menu ngang trên cùng của màn hình Mac, bạn chọn tab **Integrate** (ở các bản Xcode cũ hơn thì nó tên là **Source Control**).
3. Bấm chọn **Pull...** (Cập nhật từ server về).
4. Một cửa sổ nhỏ sẽ hiện ra hỏi bạn muốn pull từ nhánh nào (mặc định sẽ là `origin/main`), bạn chỉ cần nhấn nút **Pull** màu xanh là xong. Xcode sẽ tự động tải code và icon mới về.

### Cách 2: Dùng lệnh bằng Terminal trên máy Mac
Nếu bạn quen dùng dòng lệnh thì có thể dùng Terminal:
1. Mở ứng dụng **Terminal** trên máy Mac.
2. Di chuyển vào thư mục chứa project bằng lệnh `cd` (Ví dụ: `cd Desktop/p2premotedesktop`).
   *(Mẹo: Bạn có thể gõ chữ `cd ` rồi kéo thả thư mục project từ Finder vào Terminal, nó sẽ tự điền đường dẫn cho bạn).*
3. Gõ lệnh sau và nhấn Enter:
   ```bash
   git pull origin main
   ```

Sau khi Pull xong, bạn hãy thử Build & Run lại app trên Xcode để xem icon mới đã được cập nhật chưa nhé!

Nếu bạn không thấy nút Play màu xanh (có thể thanh công cụ Toolbar của Xcode đã bị ẩn đi), bạn có thể chạy app qua thanh Menu theo các cách sau:

**Cách 1: Chạy qua menu trên cùng**
1. Nhìn lên thanh menu ở sát mép trên cùng của màn hình Mac.
2. Bấm vào chữ **Product**.
3. Chọn **Run** trong danh sách hiện ra.

**Cách 2: Dùng phím tắt**
Bạn chỉ cần nhấn tổ hợp phím **`Command + R`** là Xcode sẽ tự động Build và Run ứng dụng.

**Cách 3: Hiển thị lại nút Play**
Nếu bạn muốn nút Play hiện lại cho dễ dùng, hãy lên menu chọn **View** -> **Show Toolbar**.

---
*Lưu ý nhỏ: Nếu chữ **Run** bị mờ không bấm được, nguyên nhân có thể là Xcode chưa nhận diện đây là một project hoàn chỉnh (ví dụ bạn chỉ mở thư mục chứa code Python thay vì mở file project `.xcodeproj` của Xcode). Lỗi `Tcl_ServiceModeHook: Notifier not initialized` là một lỗi kinh điển trên macOS khi kết hợp giao diện **Tkinter** với thư viện tạo icon dưới khay hệ thống là **pystray**.

Cả hai thư viện này đều cố gắng chiếm quyền điều khiển vòng lặp sự kiện (event loop) của macOS (AppKit/Cocoa). Đặc biệt, trong code của app, `pystray` được gọi chạy ngầm trong một luồng phụ (background thread). Trên macOS, nếu bạn gọi giao diện từ luồng phụ trong khi Tkinter đang chạy ở luồng chính, hệ điều hành sẽ lập tức báo lỗi và "giết" app (abort) để bảo mật.

Để khắc phục, mình vừa cập nhật lại file `app.py`: **Vô hiệu hóa tính năng icon khay hệ thống (pystray) trên macOS**. Việc tắt icon khay hệ thống không ảnh hưởng gì đến tính năng cốt lõi của phần mềm (như điều khiển màn hình, chat, file manager...), nó chỉ không hiện icon nhỏ ở thanh bar phía trên cùng thôi.
