   * Khi bạn merge, Git kéo trực tiếp commit gốc bạn đã tạo trước đó:
     **`222fa2e: Fix UAC on battery mode both full version and host version`**
   * Commit có tên *"Cap nhat code moi nhat sau khi detached HEAD"* không hề được sinh ra do lúc bạn gõ lệnh đó thì thư mục đang trống.

2. **Thời gian hiển thị trên GitHub là ngày hôm qua (hoặc X hours ago)**:
   * Git lưu thời gian tạo commit ban đầu (lúc **15:58 ngày 19/10**).
   * Do đó, trên giao diện GitHub nó sẽ ghi là *"yesterday"* hoặc *"14 hours ago"* chứ không ghi là *"just now"*.

3. **Trình duyệt đang lưu cache trang web**:
   * Bạn hãy nhấn tổ hợp phím **`Ctrl + F5`** (hoặc `Cmd + Shift + R`) trên trình duyệt để làm mới trang GitHub.
   * Bạn có thể bấm vào mục **Commits** trên nhánh `main` của repo, bạn sẽ thấy commit `222fa2e` đang nằm ở vị trí trên cùng.
   * Hoặc mở trực tiếp file `build_and_deploy.py` trên GitHub, bạn sẽ thấy các hàm mới như `merge_full_service`, `log_dist_size` đã có đầy đủ.
