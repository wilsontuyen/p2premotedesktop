### Cách 1: Dùng JavaScript gửi HTTP `HEAD` request (Khuyên dùng nếu file nằm trên cùng Hosting/Server)

Trình duyệt có thể gửi một yêu cầu `HEAD` tới đường link của file. Yêu cầu này **chỉ lấy phần thông tin header** (chứa kích thước `Content-Length`) mà **không tải toàn bộ file về**, do đó tốc độ phản hồi tính bằng mili-giây và không tốn băng thông.

#### Cách thức hoạt động:
1. JavaScript gọi `fetch(fileUrl, { method: 'HEAD' })`.
2. Đọc giá trị `Content-Length` (kích thước tính theo byte).
3. Đổi sang MB: `(bytes / (1024 * 1024)).toFixed(1) + ' MB'`.
4. Cập nhật trực tiếp nội dung vào thẻ hiển thị dung lượng.

#### Ví dụ đoạn mã xử lý:
```javascript
async function autoUpdateFileSize(fileUrl, targetElementId, prefix = 'Phiên bản AI PRO · ') {
    try {
        const res = await fetch(fileUrl, { method: 'HEAD' });
        const bytes = res.headers.get('content-length');
        if (bytes && !isNaN(bytes)) {
            const sizeMB = (parseInt(bytes, 10) / (1024 * 1024)).toFixed(1);
            const el = document.getElementById(targetElementId);
            if (el) el.textContent = `${prefix}${sizeMB} MB`;
        }
    } catch (error) {
        // Giữ nguyên dung lượng mặc định nếu không fetch được
        console.warn(`Không thể lấy dung lượng từ ${fileUrl}:`, error);
    }
}

// Gọi khi trang tải xong:
document.addEventListener('DOMContentLoaded', () => {
    autoUpdateFileSize('download/easy-remote-desktop-mac.dmg.zip', 'size-mac');
    autoUpdateFileSize('download/easy-remote-desktop-linux.tar.gz', 'size-linux');
    autoUpdateFileSize('download/easy-remote-desktop-android.apk', 'size-android');
});
```

*Ưu điểm:* Mỗi lần bạn thay file mới vào thư mục `download/`, web sẽ tự động nhận diện dung lượng mới mà không cần sửa code HTML.
