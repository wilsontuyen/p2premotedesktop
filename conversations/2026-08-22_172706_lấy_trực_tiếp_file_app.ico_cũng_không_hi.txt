**Lý do bạn vẫn thấy nó nhỏ và không phóng to được:**
Nguyên nhân hoàn toàn không phải do file `.exe` thiếu icon lớn, mà 100% là do **Icon Cache (bộ nhớ đệm) của Windows**. 
Khi bạn cài đè lên bản cũ, hoặc nhìn vào một Shortcut cũ, Windows Explorer rất "lười" và nó cứ lấy cái hình bé tí xíu từ trong bộ nhớ đệm (của lần cài đặt trước) ra hiện, dù bên trong file `.exe` mới đã có hình to.

**Cách để bạn kiểm chứng file `.exe` chính đã thực sự có icon lớn:**
1. Bạn hãy copy file `.exe` chính (nằm ở `C:\Apps\P2P\RemoteDesktopP2P.exe` hoặc thư mục bạn vừa cài) ra một thư mục mới tinh nào đó (hoặc copy ra thẳng ngoài Desktop).
2. Đổi tên file đó thành một tên hoàn toàn lạ, ví dụ `Easy_Test_123.exe`. (Việc đổi tên lạ để ép Windows không dùng lại cache cũ).
3. Chuột phải ra khoảng trống, chọn **View > Extra Large Icons** (hoặc Large Icons).

Bạn sẽ thấy ngay cái `.exe` chính nó sẽ hiển thị to đùng sắc nét. Nếu bạn tạo một shortcut mới từ file này, shortcut cũng sẽ to theo. Bạn cứ làm thử các bước trên để xác nhận nhé!
