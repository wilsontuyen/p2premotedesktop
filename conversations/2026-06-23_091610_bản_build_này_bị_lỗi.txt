========== MODEL ==========
Quá trình chạy lệnh `build_and_deploy.py` để biên dịch (build) bằng Nuitka, tự động đóng gói Inno Setup và triển khai (deploy) bản cập nhật lên máy chủ của bạn đã hoàn tất thành công. 

Tiến trình đã thực hiện các bước sau:
1. Dừng task và service cũ.
2. Build lại 2 tệp thực thi `RemoteDesktopService` và `RemoteDesktopP2P` kèm mọi cấu hình UI mới và logic Clipboard Agent mới.
3. Đóng gói Inno Setup.
4. Triển khai code mới nhất vào thư mục `C:\Apps\P2P`.
5. Khởi động lại Service (chạy ngầm Headless) và khởi động UI Agent cho phiên User hiện tại qua `explorer.exe`.
