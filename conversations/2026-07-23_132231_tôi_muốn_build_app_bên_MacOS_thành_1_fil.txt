========== USER ==========
tôi muốn build app bên MacOS thành 1 file thì phải làm những gì?

========== MODEL ==========
Để đóng gói ứng dụng Python thành một file chạy duy nhất trên macOS (thường là file thực thi không cần cài đặt Python hoặc file `.app`), công cụ phổ biến và dễ sử dụng nhất là **PyInstaller**.

Dưới đây là các bước để thực hiện:

### Bước 1: Cài đặt PyInstaller
Mở Terminal trên máy Mac của bạn và cài đặt PyInstaller thông qua pip:
```bash
pip install pyinstaller
```

### Bước 2: Đóng gói ứng dụng thành 1 file
Di chuyển đến thư mục chứa mã nguồn của bạn (ví dụ: thư mục chứa file `app.py`) trên Terminal của máy Mac, sau đó chạy lệnh sau:

```bash
pyinstaller --onefile --windowed app.py
```

**Giải thích các cờ (flags):**
- `--onefile` (hoặc `-F`): Yêu cầu PyInstaller gom tất cả thư viện và mã nguồn thành **một file thực thi duy nhất**.
- `--windowed` (hoặc `-w`): Ẩn cửa sổ dòng lệnh (Terminal) khi ứng dụng chạy. Điều này rất quan trọng đối với các ứng dụng có giao diện đồ họa (GUI). Nếu ứng dụng của bạn là dạng console/CLI, bạn hãy bỏ cờ này đi.
- `app.py`: Là file chạy chính (entry point) của ứng dụng.

### Bước 3: Lấy file kết quả
Sau khi quá trình chạy xong (có thể mất một lúc tùy vào dung lượng các thư viện), PyInstaller sẽ tạo ra một vài thư mục mới: `build/`, `dist/`, và một file `app.spec`.

- File ứng dụng của bạn sẽ nằm trong thư mục **`dist/`**.
- Đối với macOS, PyInstaller có thể tạo ra một file thực thi UNIX hoặc một thư mục `.app` (nếu dùng `--windowed`). Bạn có thể phân phối file/thư mục này cho người dùng macOS khác.

### ⚠️ Một số lưu ý quan trọng khi build trên macOS:
1. **Phải build trên máy Mac**: Để tạo ra file chạy cho macOS, bạn bắt buộc phải chạy lệnh PyInstaller trên hệ điều hành macOS. (Bạn không thể build file cho Mac từ Windows).
2. **Kiến trúc chip**: Nếu bạn build trên máy Mac dùng chip Intel, ứng dụng sẽ chạy tốt trên máy Mac Intel. Nếu build trên Mac dùng chip Apple Silicon (M1/M2/M3), ứng dụng sẽ chạy native trên ARM. Thường macOS có Rosetta 2 để dịch chéo, nhưng tốt nhất nên build một bản Universal (hỗ trợ cả hai) nếu cần phân phối rộng rãi.
3. **Thêm các file tài nguyên**: Nếu ứng dụng của bạn sử dụng hình ảnh, icon, hoặc các file cấu hình đi kèm, bạn sẽ cần thêm cờ `--add-data` hoặc chỉnh sửa file `.spec` để PyInstaller biết và đóng gói kèm các file đó.
   - Ví dụ: `pyinstaller --onefile --windowed --add-data "assets/*:assets" app.py`

Bạn có muốn mình tạo sẵn một file script hoặc file cấu hình (spec) để bạn có thể dễ dàng cấu hình đường dẫn, hình ảnh và icon cho ứng dụng không?

========== USER ==========
tôi muốn build ở dạng 1 file duy nhất như install.exe bên windows để người dùng MacOS có thề cài đặt và chạy mà không cần quan tâm cần phải cài những gói phần mềm nào và app chạy được trên tất cả các loại chip

========== MODEL ==========
Để tạo ra một file cài đặt duy nhất cho macOS (tương đương với file `install.exe` bên Windows, chứa sẵn mọi thứ) và **chạy được trên cả chip Intel và Apple Silicon (M1, M2, M3,...)**, bạn cần tạo ra một **Universal Binary** và sau đó đóng gói nó thành file **`.dmg`** (Disk Image) hoặc file **`.pkg`** (Installer Package).

Trên macOS, định dạng cài đặt phổ biến và được yêu thích nhất là **.dmg**. Người dùng chỉ cần nhấp đúp vào file `.dmg` và kéo thả ứng dụng vào thư mục Applications. 

Dưới đây là các bước chi tiết để bạn thực hiện **trên máy Mac**:

### Bước 1: Chuẩn bị môi trường Python Universal2
Để build ứng dụng chạy được trên mọi loại chip Mac, bản thân phiên bản Python bạn dùng để build **phải là phiên bản hỗ trợ Universal2** (hỗ trợ cả hai kiến trúc `x86_64` và `arm64`).
1. Tải và cài đặt Python bản chuẩn (official installer) từ trang `python.org` dành cho macOS. Các bộ cài macOS từ Python 3.9 trở lên thường hỗ trợ sẵn "macOS 64-bit universal2".
2. Khởi tạo môi trường ảo (virtual environment) và cài đặt thư viện bằng phiên bản Python này:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   pip install pyinstaller
   ```

### Bước 2: Đóng gói thành ứng dụng macOS (.app) với PyInstaller
Bạn cần yêu cầu PyInstaller build ứng dụng dưới dạng Universal Binary. Chạy lệnh sau trong Terminal (đảm bảo đang ở trong môi trường ảo):

```bash
pyinstaller --windowed --target-architecture universal2 app.py
```
*Lưu ý:*
- `--windowed`: Bắt buộc để tạo ra ứng dụng có giao diện Mac chuẩn (thư mục `.app` thay vì một file chạy bằng Terminal).
- `--target-architecture universal2`: Cờ này chỉ định PyInstaller gom cả kiến trúc Intel và ARM vào ứng dụng.

Sau khi lệnh chạy xong, bạn sẽ thấy một thư mục có tên `app.app` (hoặc tên app của bạn) nằm trong thư mục `dist/`. Đây là ứng dụng đã chứa mọi thư viện cần thiết, người dùng không cần cài thêm Python hay bất kỳ gói nào khác.

### Bước 3: Đóng gói .app thành file cài đặt .dmg
Để có trải nghiệm cài đặt chuyên nghiệp như `install.exe` bên Windows (kéo thả để cài đặt), bạn sẽ dùng công cụ `create-dmg` để đóng gói thư mục `.app` thành một file `.dmg` duy nhất.

1. **Cài đặt create-dmg** (thông qua Homebrew trên Mac):
   ```bash
   brew install create-dmg
   ```

2. **Chạy lệnh tạo file DMG**:
   Di chuyển vào thư mục `dist/` và chạy lệnh sau:
   ```bash
   cd dist
   create-dmg \
     --volname "My App Installer" \
     --window-pos 200 120 \
     --window-size 600 400 \
     --icon-size 100 \
     --icon "app.app" 150 190 \
     --hide-extension "app.app" \
     --app-drop-link 450 190 \
     "MyApp-Installer.dmg" \
     "app.app"
   ```
   *(Thay đổi `app.app` bằng tên thực tế của ứng dụng bạn).*

**Kết quả:** Bạn sẽ có một file `MyApp-Installer.dmg`. Khi người dùng Mac tải về, họ mở file này lên sẽ thấy một cửa sổ hướng dẫn kéo ứng dụng vào thư mục Applications. Khi đó, nó đã được cài đặt vào máy của họ.

### (Tùy chọn) Đóng gói dạng Installer Wizard (.pkg)
Nếu bạn vẫn thích dạng trình cài đặt có các nút "Next", "Continue", "Agree" giống hệt bộ cài `.msi`/`.exe` truyền thống trên Windows, macOS hỗ trợ công cụ gốc tên là `pkgbuild`.

Chạy lệnh này (thay thế đường dẫn tương ứng):
```bash
pkgbuild --install-location /Applications --component dist/app.app MyApp-Installer.pkg
```
Người dùng chạy file `.pkg` sẽ trải qua quá trình cài đặt từng bước bằng trình cài đặt hệ thống của Mac.

1. Build `Universal2 .app` bằng **PyInstaller** (giải quyết đa nền tảng chip & gói gọn môi trường).
2. Đóng gói `.app` thành **.dmg** bằng **create-dmg** (tạo bộ cài đặt 1 file duy nhất cho người dùng tải).
