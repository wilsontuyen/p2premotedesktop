========== MODEL ==========
Để ứng dụng (app) này có thể chạy được trên Windows 7, chúng ta phải giải quyết 2 rào cản lớn:

1. **Phiên bản Python**: Hiện tại bạn đang sử dụng phiên bản Python rất mới để biên dịch Nuitka (vượt quá 3.8). Bắt đầu từ Python 3.9, Python đã chính thức **ngừng hỗ trợ Windows 7**. File `.exe` được build ra bằng Python 3.9 trở lên sẽ báo lỗi thiếu `api-ms-win-core-path-l1-1-0.dll` khi chạy trên Windows 7.
2. **Script cài đặt (Inno Setup / bat)**: Các script cài đặt service ngầm hiện đang sử dụng module `ScheduledTasks` của PowerShell (`Register-ScheduledTask`, `New-ScheduledTaskAction`...). Những lệnh này chỉ hỗ trợ từ **Windows 8** trở lên, còn Windows 7 dùng PowerShell 2.0 mặc định sẽ báo lỗi không tìm thấy lệnh.
