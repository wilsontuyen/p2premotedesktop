========== MODEL ==========
**Cách lấy tọa độ chính xác của mục **Paste** trong menu chu‑mouse‑right của Windows 11**

> **Lưu ý:** Ở Windows 11 vị trí của menu ngữ cảnh thay đổi tùy vào độ phân giải, tỷ lệ DPI và theme (dark/light). Vì vậy cách “hard‑code” một tọa độ cố định sẽ không ổn định. Thay vào đó, hãy dùng **UI Automation** để truy vấn vị trí (`BoundingRectangle`) của mục “Paste”. Dưới đây là 3 cách phổ biến (Python → PowerShell → C#) bạn có thể dùng tùy môi trường.

## 1️⃣ Python – `pywinauto`

```python
# pip install pywinauto
import time
from pywinauto import Application, mouse, findwindows

# 1. Mở cửa sổ Explorer (hoặc nơi bạn muốn paste)
app = Application(backend="uia").connect(path="explorer.exe")
dlg = app.top_window()

# 2. Kích chuột phải tại vị trí muốn mở menu
mouse.move(coords=(500, 400))   # vị trí file/folder bạn muốn paste
mouse.right_click(button='right')
time.sleep(0.3)                 # cho menu hiện ra

# 3. Tìm mục "Paste" trong menu hiện tại
menu = dlg.child_window(control_type="Menu")
paste_item = menu.child_window(title="Paste", control_type="MenuItem")

# 4. Lấy BoundingRectangle → (left, top, right, bottom)
rect = paste_item.rectangle()
print(f"Paste: left={rect.left}, top={rect.top}, "
      f"right={rect.right}, bottom={rect.bottom}")

# 5. (Tuỳ chọn) Click ngay vào vị trí trung tâm
center = (rect.left + rect.right) // 2, (rect.top + rect.bottom) // 2
mouse.click(button='left', coords=center)
```

**Ưu điểm**  
- Tự động đọc vị trí thực tế, không phụ thuộc vào DPI.  
- Có thể tích hợp vào script tự động hoá toàn bộ workflow.

## 2️⃣ PowerShell – `UIAutomation` module

```powershell
# Cài module (chỉ chạy 1 lần)
Install-Module -Name UIAutomation -Scope CurrentUser -Force

Import-Module UIAutomation

# 1. Mở Explorer và di chuột phải (hoặc dùng Send-Keys)
#    (đây là ví dụ đơn giản, bạn có thể dùng Send-Keys để mở menu)
Set-CursorPosition -X 800 -Y 500
Send-Keyboard -Key 'Apps'   # phím Context Menu

Start-Sleep -Milliseconds 300   # chờ menu hiện ra

# 2. Lấy đối tượng menu và mục Paste
$menu = Get-UiaWindow -Name 'FolderView' | Get-UiaMenu
$paste = $menu | Get-UiaMenuItem -Name 'Paste'

# 3. Thu thập BoundingRectangle
$rect = $paste.Current.BoundingRectangle
Write-Host "Paste vị trí: Left=$($rect.Left) Top=$($rect.Top) " `
           "Right=$($rect.Right) Bottom=$($rect.Bottom)"

# 4. Click vào trung tâm (tùy chọn)
$centerX = ($rect.Left + $rect.Right) / 2
$centerY = ($rect.Top + $rect.Bottom) / 2
Set-CursorPosition -X $centerX -Y $centerY
Send-Keyboard -Key 'Enter'   # hoặc mouse click
```

**Ưu điểm**  
- PowerShell đã có sẵn trên Windows, không cần cài Python.  
- `UIAutomation` cho phép truy cập đầy đủ các thuộc tính UI.

## 3️⃣ C# – Windows UI Automation API

```csharp
using System;
using System.Windows.Automation;

class PasteCoordinates
{
    static void Main()
    {
        // 1. Mở menu chuột phải (có thể dùng SendInput từ Win32)
        //    Ở đây giả sử menu đã mở rồi.

        // 2. Tìm menu hiện tại (có class "ContextMenu")
        AutomationElement root = AutomationElement.RootElement;
        Condition cond = new PropertyCondition(AutomationElement.ControlTypeProperty,
                                               ControlType.Menu);
        AutomationElement menu = root.FindFirst(TreeScope.Subtree, cond);

        // 3. Tìm mục "Paste"
        Condition pasteCond = new AndCondition(
            new PropertyCondition(AutomationElement.ControlTypeProperty,
                                  ControlType.MenuItem),
            new PropertyCondition(AutomationElement.NameProperty, "Paste"));
        AutomationElement pasteItem = menu.FindFirst(TreeScope.Children, pasteCond);

        // 4. Lấy vị trí
        if (pasteItem != null)
        {
            var rect = pasteItem.Current.BoundingRectangle;
            Console.WriteLine($"Paste: Left={rect.Left}, Top={rect.Top}, " +
                              $"Right={rect.Right}, Bottom={rect.Bottom}");
        }
        else
        {
            Console.WriteLine("Không tìm thấy mục Paste (có thể ngôn ngữ khác).");
        }
    }
}
```

**Ưu điểm**  
- Thích hợp khi bạn đang viết một ứng dụng Windows native.  
- Không phụ thuộc vào DPI vì `BoundingRectangle` luôn trả về tọa độ thực tế trên màn hình.

## 🔧 Một số lưu ý thực tế khi dùng tọa độ

| Yếu tố | Ảnh hưởng | Giải pháp |
|--------|-----------|-----------|
| **DPI / Scaling** | Thay đổi kích thước menu, vị trí các mục | Luôn lấy `BoundingRectangle` từ UI Automation thay vì tính toán thủ công. |
| **Theme (Light/Dark)** | Các biểu tượng có màu khác, nhưng vị trí không đổi | Không ảnh hưởng nếu dùng UIA. |
| **Thứ tự mục Menu** | Khi thư mục trống, “Paste” thường là mục đầu tiên; khi có mục “Cut”/“Copy” thì lại là mục thứ 2. | UI Automation tìm theo tên, không quan tâm vị trí trong danh sách. |
| **Ngôn ngữ hệ thống** | Tên mục có thể là “Dán” trong tiếng Việt hoặc “Paste” trong tiếng Anh. | Dùng `AutomationElement.Name` để kiểm tra ngôn ngữ hiện tại, hoặc xét cả hai giá trị. |
| **Chiều cao menu thay đổi** | Khi có nhiều mục (View, Sort by, …) chiều cao tổng tăng, các mục phía dưới dịch xuống. | Lấy vị trí từng mục riêng biệt, không dựa vào offset tĩnh. |

## 1️⃣ Python – `pywinauto` (UI Automation backend)

> **Yêu cầu**: Python 3.x, `pip install pywinauto`  

```python
# --------------------------------------------------------------
#  paste_by_uia.py
# --------------------------------------------------------------
"""
Tự động mở menu ngữ cảnh, lấy tọa độ mục "Paste"
và click vào chính xác vị trí trung tâm.
- Sử dụng UI Automation (pywinauto) → không phụ thuộc DPI.
- Hoạt động trên Windows 11 (tiếng Anh). 
  Đối với ngôn ngữ khác, thay đổi `title="Paste"` sang tên
  tương ứng, ví dụ "Dán" (tiếng Việt).
"""

import time
from pywinauto import Application, mouse, findwindows
from pywinauto.keyboard import send_keys

# ------------------------------------------------------------------
# 1. Kết nối tới Explorer (hoặc bất kỳ cửa sổ nào đang mở)
# ------------------------------------------------------------------
# Nếu Explorer chưa mở, bạn có thể khởi động:
#   subprocess.Popen(["explorer.exe"])
app = Application(backend="uia").connect(path="explorer.exe")
# Lấy cửa sổ Explorer đang hoạt động (thường là top window)
dlg = app.top_window()

# ------------------------------------------------------------------
# 2. Di chuyển chuột tới vị trí file/folder mà bạn muốn Paste
# ------------------------------------------------------------------
# Bạn có thể tính toán hoặc hard‑code tọa độ tạm thời.
# Ví dụ: (x, y) = (800, 500) – vị trí trung tâm của một item.
target_x, target_y = 800, 500
mouse.move(coords=(target_x, target_y))
time.sleep(0.1)

# ------------------------------------------------------------------
# 3. Mở menu ngữ cảnh (chuột phải) và chờ menu hiện ra
# ------------------------------------------------------------------
mouse.right_click(button='right')
time.sleep(0.3)   # Đảm bảo menu đã hiện ra đủ thời gian

# ------------------------------------------------------------------
# 4. Tìm mục “Paste” trong menu hiện tại
# ------------------------------------------------------------------
# Trong UIA, menu được biểu diễn như một ControlType.Menu
menu = dlg.child_window(control_type="Menu")
# Nếu menu không được tìm thấy, có thể cần dùng `dlg.wrapper_object().children()`
# để duyệt các phần tử con và lấy phần tử có ControlType.Menu.
paste_item = menu.child_window(title="Paste", control_type="MenuItem")

# Nếu Windows của bạn đang dùng ngôn ngữ khác, thay "Paste" bằng
#   "Dán" (tiếng Việt) hoặc tương đương.
if not paste_item.exists():
    raise RuntimeError("Không tìm thấy mục 'Paste' – "
                       "kiểm tra ngôn ngữ hệ thống hoặc vị trí menu.")

# ------------------------------------------------------------------
# 5. Lấy BoundingRectangle → (left, top, right, bottom)
# ------------------------------------------------------------------
rect = paste_item.rectangle()
print(f"BoundingRectangle of Paste: left={rect.left}, top={rect.top}, "
      f"right={rect.right}, bottom={rect.bottom}")

# ------------------------------------------------------------------
# 6. Click vào trung tâm của mục Paste
# ------------------------------------------------------------------
center_x = (rect.left + rect.right) // 2
center_y = (rect.top + rect.bottom) // 2
mouse.click(button='left', coords=(center_x, center_y))

# --------------------------------------------------------------
# Kết thúc – file đã được Paste thành công
# --------------------------------------------------------------
```

## 3️⃣ C# – Windows UI Automation API (đối với ứng dụng WinForms/WPF)

> **Yêu cầu**: .NET 6 hoặc .NET Framework, Visual Studio.

```csharp
// --------------------------------------------------------------
//  PasteByUIA.cs
// --------------------------------------------------------------
using System;
using System.Windows.Automation;

class PasteByUIA
{
    static void Main()
    {
        // 1. Giả sử menu ngữ cảnh đã mở (chuột phải trên một file/folder)
        //    Nếu chưa, bạn có thể dùng SendInput hoặc Win32 mouse_event để mở.
        //    Ở đây chúng ta chỉ tập trung vào việc tìm và click mục Paste.

        // 2. Tìm cửa sổ menu (class: "#32768" – ContextMenu)
        var root = AutomationElement.RootElement;
        var menuCond = new PropertyCondition(
            AutomationElement.ControlTypeProperty,
            ControlType.Menu);
        var menu = root.FindFirst(TreeScope.Subtree, menuCond);

        if (menu == null)
        {
            Console.WriteLine("Không tìm thấy ContextMenu. "
                              + "Hãy chắc chắn rằng menu đã mở.");
            return;
        }

        // 3. Tìm mục "Paste" (hoặc "Dán" nếu hệ thống tiếng Việt)
        var pasteCond = new AndCondition(
            new PropertyCondition(AutomationElement.ControlTypeProperty,
                                  ControlType.MenuItem),
            new PropertyCondition(AutomationElement.NameProperty, "Paste"));
        var pasteItem = menu.FindFirst(TreeScope.Children, pasteCond);

        if (pasteItem == null)
        {
            Console.WriteLine("Không tìm thấy mục 'Paste' – "
                              + "có thể do ngôn ngữ khác.");
            return;
        }

        // 4. Lấy BoundingRectangle
        var rect = pasteItem.Current.BoundingRectangle;
        Console.WriteLine($"Paste BoundingRectangle: Left={rect.Left}, " +
                          $"Top={rect.Top}, Right={rect.Right}, Bottom={rect.Bottom}");

        // 5. Click vào trung tâm
        var clickX = (rect.Left + rect.Right) / 2;
        var clickY = (rect.Top + rect.Bottom) / 2;
        System.Windows.Point clickPoint = new System.Windows.Point(clickX, clickY);

        // Dùng Win32 API để click (mouse_event)
        NativeMethods.SetCursorPos((int)clickX, (int)clickY);
        NativeMethods.mouse_event(NativeMethods.MOUSEEVENTF_LEFTDOWN, 0, 0, 0, 0);
        NativeMethods.mouse_event(NativeMethods.MOUSEEVENTF_LEFTUP, 0, 0, 0, 0);
    }
}

// ------------------------------------------------------------------
//  Win32 helper
// ------------------------------------------------------------------
internal static class NativeMethods
{
    public const int MOUSEEVENTF_LEFTDOWN = 0x02;
    public const int MOUSEEVENTF_LEFTUP   = 0x04;

    [System.Runtime.InteropServices.DllImport("user32.dll")]
    public static extern bool SetCursorPos(int X, int Y);

    [System.Runtime.InteropServices.DllImport("user32.dll")]
    public static extern void mouse_event(int dwFlags, int dx, int dy,
                                          int dwData, int dwExtraInfo);
}
```
