1. Tắt các tiến trình P2P đang chạy.
2. Build lại toàn bộ service và GUI của phần mềm thông qua **Nuitka** (Tạo file EXE).
3. Đóng gói file cài đặt `EasyRemoteDesktop_Installer.exe`.
4. Triển khai (Deploy) lại các file vào `C:\Apps\P2P` và khởi động lại **RemoteDesktopP2P.exe**.

**Lưu ý quan trọng:** Tính năng Tải về (Download) cho thư mục vừa được viết thêm logic xử lý ở phía Android bên trong file `DataTransferClient.kt`. Sau đó, bạn có thể kiểm tra tính năng copy thư mục và nhiều file cùng lúc trên cả 2 chiều PC <-> Android.
