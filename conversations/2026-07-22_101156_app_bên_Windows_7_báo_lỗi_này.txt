### Nguyên nhân
Kể từ phiên bản 3.8, thư viện nòng cốt của Python khi nạp các file đuôi `.pyd` (như `_socket.pyd`) hoặc `.dll` đã sử dụng hàm hệ thống `LoadLibraryExW` kèm theo một tham số (cờ) có tên là `LOAD_LIBRARY_SEARCH_DEFAULT_DIRS` để tăng cường tính bảo mật. 

Vấn đề là hệ điều hành Windows 7 gốc ban đầu chưa hỗ trợ cờ này. Microsoft chỉ thêm hỗ trợ cho cờ này thông qua một bản cập nhật về sau. Do máy Windows 7 mà bạn đang chạy app chưa được cài đặt bản cập nhật đó, nên hệ điều hành báo lỗi tham số không hợp lệ ("The parameter is incorrect").

### Cách khắc phục (trên máy khách Windows 7)
Để khắc phục lỗi này, máy tính chạy Windows 7 đó cần cài đặt thêm một số bản vá cập nhật của Microsoft:

1. **Cài đặt bản cập nhật KB2533623 hoặc KB3063858:** 
   Đây là bản cập nhật cốt lõi sửa lỗi bổ sung tham số cho API của Windows. Bạn có thể tìm tải bản cập nhật **KB3063858** (bản cập nhật mới hơn thay thế cho KB2533623) trên trang **Microsoft Update Catalog** và tiến hành cài đặt.
2. **Đảm bảo đã có SP1:** Máy tính đó phải đang chạy phiên bản Windows 7 có Service Pack 1 (SP1).
3. **Cài đặt Visual C++ Redistributable:** Hãy chắc chắn máy tính đã cài đặt bản *Microsoft Visual C++ Redistributable 2015-2022* (bản x86 hoặc x64 tùy thuộc vào việc app của bạn build 32bit hay 64bit).
