- Khi bạn copy từ Client sang Host -> máy nhận file là máy **Host** (máy mà chúng ta vừa mới sửa code và chạy `build_and_deploy.py`). Lúc này code mới đã hoạt động, nhận diện được sự kiện Paste, cho phép tải file về thành công.
